# STEP｜キャリアステップシート

SNS部署のインターン生のキャリアステップを管理するアプリです。

| URL | 誰が使う |
|---|---|
| `/` | インターン本人（スマホ想定） |
| `/admin.html` | 育成・UL（PC想定） |

セットアップと使い方は **[SETUP.md](SETUP.md)** にまとめています。

名簿を一括で用意する必要はありません。**各メンバーが自分で登録した情報が、
そのまま管理者ツールの一覧に積み上がっていきます。**
デモデータは持っていないので、管理者ツールに出るのは実際に登録した人だけです。

## ログインの考え方

| 入れるもの | 誰に配る | いつ使う |
|---|---|---|
| **共通パスコード** | メンバー全員 | 登録するときだけ（部署の人かどうかの確認） |
| **自分のパスワード** | 本人だけ | 毎回のログイン。登録のときに各自で決める。あとから自分で変えられる |
| **ログイン用コード** | その人ひとり | パスワードを忘れたとき。UL・育成が発行して本人に渡す（8文字・使い捨て） |
| **管理者キー** | 育成・ULだけ | 育成・ULになることを申請するとき（初回のみ） |

パスワードを1人1つにしているので、共通パスコードを知っているだけでは
他人としてログインできません。UL になりすまして全員分を見ることもできません。

パスワードの決め直しに**共通パスコードを使わない**のも同じ理由です。
共通パスコードは全員が知っているため、それで決め直せると、名前を検索して
「パスワードを決める ›」の人を見つけた誰もが、その人になりすませてしまいます。
決め直しには、UL・育成がその場で発行する**本人ひとりにしか渡らないコード**を使います。

ログイン画面では名簿を一覧表示せず、**名前を2文字以上入れた人にだけ候補を返します。**
権限は **メンバー／育成／UL** の3つ。育成とULでできることは同じで、
どちらも管理者ツールで全員を見られます（表示上の役割と「担当」の出かたが違うだけ）。
育成・ULになるには**管理者キー**が要ります。キーが合っていればその場で権限が付きます
（承認待ちはありません）。キーを続けて5回間違えると15分ロックされます。

## 半期ごとのユニット編成

`members` の所属・UL は1カラムしか無いので、編成替えで上書きすると
前期の情報が消えてしまいます。そこで **期（`terms`）** と
**期ごとの割当（`assignments`）** を別に持っています。

管理者ツールの **期・ユニット編成** タブで、期をつくって割当を入れます。
**編成ボード**でカードをドラッグすると、その場でバランス（人数・グレードの分布・
合計稼働・担当社数・育成負荷・昇格対象・遅れ）と警告が変わります。
ドラッグが使えないときは「表で直す」に切り替えられます。
**確定を押すまで、いまの名簿は変わりません。**

「この2人は同じユニットにする／別にする」は **組み合わせの決めごと** として残せます。
次の期にも引き継がれ、**自動で割り振る**ときにも守られます。
自動割り振りが見ているのは「面倒を見られる人（G5+）が各ユニットにいるか」と
「週の稼働時間の合計が均されているか」の2つだけなので、叩き台として使ってください。
確定すると割当が名簿に書き戻され、所属やULが変わった人には申し送りが1件ずつ残ります。
前の期の割当は消えないので、個人カルテの「所属の履歴」から後から引けます。

### 引き継ぎシート

期が変わるときに、**前のULが次のULに渡すぶん**を書きます。
強み／苦手・つまずきやすいところ／コミュニケーションのクセ／地雷／
次のULにまず最初にやってほしいこと、の5項目です（本人の画面には出ません）。

うち3つ（強み・苦手・次にやってほしいこと）が埋まると記入済みになり、
期・ユニット編成タブに **記入率** と、まだ書けていない人が**前のULごと**に並びます。
「やった人だけやる」ではなく「全員ぶんそろえる」に変えるための仕掛けです。
そろったら1人1枚の紙としてまとめて印刷できます。

この機能には `supabase/schema.sql` の貼り直しが必要です。
貼っていないあいだは、タブを開いたときにその案内だけが出ます。

## 個人カルテ

管理者ツールでメンバーの名前を押すと、その人の**カルテ**が開きます。
最初に出るのは読む画面で、本人がマイシートに書いた言葉（相棒の名前・
卒業時の目標・五箇条・気にしていること）、いまの稼働（週の稼働時間・
担当アカウント数・卒業予定・得意領域）、カテゴリ別の強み弱み、
直近6ヶ月の進捗の推移、直近の申し送りが1枚に並びます。
**印刷／PDF** で1人1枚として出せるので、半期ごとの引き継ぎにそのまま使えます。

チェックを入れる操作は隣の「チェック」タブに分けてあります。

## チェック

**本人が画面でチェックを入れた時点で達成**です。承認はありません。
昇格判断に使う進捗率も、本人のチェックでそのまま数えます。
入れ間違えたときは本人がそのまま外せます。
育成・UL は管理者ツールから、面談しながら代わりに付けたり外したりできます。

パスワードを忘れた人は、ログイン画面の **「パスワードを忘れた」** から
その場で **UL・育成にリセットを依頼** できます。依頼は管理者ツールの
**今日のアクションの一番上**に出るので、育成・UL はそこから1クリックで
リセットし、表示された **ログイン用コード（8文字）** を本人に渡します
（コードを含んだ、本人に送る文もそのままコピーできます）。

コードは**1回しか表示されません**。控えそこねたら発行し直してください。
チェックや申し送りなどの記録は消えず、パスワードだけ決め直せます。

パスワードを**忘れていなくても**、マイシートの **設定 → ログイン** から
本人がいつでも変えられます。

## ファイル構成

```
index.html            インターン本人の画面
admin.html            育成・ULの管理者ツール
sw.js                 画面のキャッシュ（電波が無くても開けるようにする）
shared/config.js      Supabaseの接続情報（ここだけ編集する）
shared/steps.js       キャリアステップの定義（GRADES）と進捗の計算
shared/ui.js          共通の見た目パーツ・日付やCSVの整形
shared/store.js       データの読み書き（Supabase）・オフライン時の送信待ち
supabase/schema.sql   Supabaseに貼るSQL（テーブルとアクセス制御）
```

`supabase/schema.sql` は何度でも貼り直せます。まだ貼っていない機能（名前検索・
しきい値の共有など）は自動で検出してオフになるので、
古いまま動かしてもこれまでどおり使えます。いまの状態は管理画面の
**設定 → この環境で使える機能** で確認できます。

ビルドは不要です。静的ファイルのまま Vercel に置けば動きます。

`shared/config.js` が空のあいだは、両方の画面が
「接続先が設定されていません」という案内だけを出します。
Supabase の情報を入れると使えるようになります（**[SETUP.md](SETUP.md)** 手順1〜4）。
